# Transwarp

> Transwarp Technology (星环科技) is a Shanghai-based enterprise big data and AI
> infrastructure software company. Its self-hosted platform includes Transwarp
> Data Hub (TDH), the Inceptor SQL analytics engine, Slipstream stream
> computing, Hyperbase wide-table store, StellarDB graph database, TimeLyre
> time-series, Scope search, ArgoDB analytical database, the Sophon AI platform
> (Base/MLDev/MLOps/LLMOps), the TDC data cloud, and the Hippo distributed
> vector database. Hippo ships documented RESTful and Python APIs with an
> official hippo-api client on PyPI. No public llms.txt was found on
> www.transwarp.cn (404 on 2026-07-21); this file was generated from the API
> Evangelist catalog entry.
